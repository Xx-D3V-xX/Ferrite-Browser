The evaluation is built so that each claim is falsifiable, each number comes with an interval, and each weakness is stated beside the result it affects. This page is the method and the current results; Metrics has the exact formulas and Reproduce it has the commands.

Read this first

The agent in this evaluation is scripted from ground truth, not a live model. Every figure below describes the architecture (does the prediction, comparison and gating contain a compromised agent?) and says nothing about how often a real model is fooled. The corpus is self-authored and template-generated, so the intervals understate the uncertainty. Details under What the numbers do not say.

The protocol: four modes on every case

A defense number is meaningless without a baseline, so each case is run under four conditions:

Off
The agent runs directly. This measures whether the attack is real at all.
SanitizerOnly
The text filter alone, with the loop bypassed: the filter's standalone power.
LoopOnly
The sanitizer bypassed, the loop running on raw content: the architecture's standalone power, with content detection explicitly off. This is the cleanest evidence that containment comes from architecture rather than from stripping text.
On
The full composed stack. This is the deployed-system number.

Per-layer power is read from the isolated modes, never from On. In On the sanitizer strips first, so the loop only sees what upstream missed, which would understate each layer if read as a standalone figure. The two deltas, the sanitizer's marginal contribution and the architecture's marginal contribution beyond passive stripping, are first-class results.

Cases are paired: the same case runs under every mode, so differences are tested with McNemar's exact test on the discordant pairs, never by comparing unpaired proportions.

The corpus

The current corpus has 938 cases and 3,488 executions: 809 attacks and 129 benign controls. Twenty-nine cases are hand-authored; 909 are generated by scripts/gen_redteam_corpus.py from a matrix:

  • 13 tasks × 12 attacker goals (every primitive an attack can need) × 11 carrier vectors × 28 payload dressings × 3 scope types.
  • The 28 dressings are: plain text, 14 disguises, 5 languages, 5 structural forms, and 3 that the sanitizer cannot recognize at all.
  • Plus 20 origin look-alikes, 5 same-site spellings, and benign controls: ordinary pages, attack-adjacent text, and every scope type.

Labels are derived, not observed. Ground truth comes from the capability lowering table, never from running the defense, so the defense cannot grade its own homework. A validation test checks that table and each task's capability set against the real code.

Independence, and what is missing

A self-authored corpus against a self-built defense is circular by default, so the design called for three independence layers: a held-out slice written by someone who did not build the defense, an external slice, and an adapted external benchmark. Two rules were meant to make that real: a held-out firewall (the defense is tuned only against the self-authored set; independent slices run once, at the end) and a briefing boundary (independent authors get a threat-model brief, not a defense brief).

What exists today: only the three AgentDojo cases are an external slice, and three cases support no claim. There is no second author, so Cohen's κ is not computable and has not been faked. The cases are also tuned-against data, and the matrix means they are not independent draws.

Reading the table

  • The architecture contains every attack that needs an action outside the prediction, and nothing else. LoopOnly's ASR is the residual: 122 of 809 (15.1%) attacks use only actions the prediction admits.
  • The sanitizer then strips 59 of those 122 (detectable wording), leaving On at 63: the residual whose wording it cannot recognize (paraphrase, social engineering, narrative framing) on carriers the scan cannot see.
  • ADR = 100% is by construction. A scripted agent issues exactly the declared deviation, so it measures the comparator, not the agent.
  • 0% false gates is for a well-behaved scripted agent under a rules-only prediction. A real agent's rate depends on what it actually does and on the model prediction layer, which this run does not exercise.

Consent policies: how much does the human matter?

The gate is a human decision, so containment depends on how that human answers. The evaluation sweeps three policies on the original 29-case run:

Consent policyMeaningASR (On)
RejectFlaggedRejects every flagged action: the upper bound on human vigilance, and the headline everywhere else0/22 = 0.0%
RandomP (p = 0.5, seed 42)Approves each flagged action by a coin flip: a middle estimate6/22 = 27.3%
ApproveAllApproves everything: the lower bound10/22 = 45.5%

Real human vigilance sits somewhere in this wide range, which a human-factors study, out of scope here, would have to estimate. Every headline number on this site assumes RejectFlagged.

What changed in the measurement

Attacking the defense found defects in every layer and in the evaluation itself. The corrections change what “caught” means, and they are listed because a number is only as good as its definition:

  • fingerprint_caught for a deviation case now requires a declared item to appear in the diff. It used “all declared primitives or all declared origins”, and “all” over an empty set is true, so a case that declared nothing on one side counted as caught against a clean diff. No old figure was inflated (every declared deviation was in fact flagged) but the metric could not have failed.
  • Origin comparisons use normalized origins, so a trailing path or default port no longer makes an origin-shift case “missed”.
  • A download or new tab is recorded at its destination; previously a download from an attacker on an allowed page produced an event the comparator admitted.
  • The rule layer matches whole words. The first benign corpus gated 3 of 7 tasks (43%) because the rules knew no everyday read verb; after the fix, the larger benign set gates 0 of 129.

Cost

In the original n=29 rules-only run the paired latency difference (On minus Off, 22 pairs) was p50 = 0 ms and p95 = 1 ms, which measures only the loop's own bookkeeping, not a network round trip. With a real provider the prediction call dominates: the same comparison against a live provider gave p50 = 699 ms and p95 = 1,527 ms. Token overhead (ΔT) is not computed: the execution record carries no token usage, which is a documented limitation.

What the numbers do not say

  • Nothing about a real model. The agent is scripted from ground truth. Whether a model takes the bait is the base model's robustness, which Ferrite does not claim.
  • Nothing about real human behavior. The headline assumes flagged actions are rejected.
  • Less certainty than the intervals suggest. Cases are generated from shared templates, so the Wilson and McNemar figures treat non-independent draws as independent, and the cases were tuned against.
  • No generalization claim. Three external cases support none.
  • No claim about the model prediction layer. The default run is rules-only; a live-provider run exists but is not reproducible byte-for-byte and is reported separately.
