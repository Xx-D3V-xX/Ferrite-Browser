Ferrite is a Rust browser, built on the Servo engine, for AI agents. Its research contribution is an architectural defense against indirect prompt injection (IPI), together with a published evaluation of how well that defense works and where it does not.

The idea in one minute

An agent that browses reads content it does not control. Some of it can carry instructions aimed at the agent rather than the user: a hidden element, an HTML comment, an image alt attribute, a field in a tool's JSON response. Ferrite does not try to win the arms race of recognizing every phrasing of an injected instruction. It watches what the agent does:

  1. Predict the task's expected fingerprint, meaning which capabilities and which sites it legitimately needs, from your request alone and before any untrusted content is read.
  2. Dry-run the agent's plan against synthetic data with no real network reachable.
  3. Compare what the agent attempted against what was predicted.
  4. Consent-gate everything beyond the prediction, in a trusted panel decoupled from page content, before anything real runs.

A successful injection can still make the agent try something unexpected. Trying it during a contained dry run, then meeting a consent prompt you control, is a very different outcome from doing it for real. A SHA-256 hash-chained audit log records the security-relevant events, so containment is verifiable after the fact.

Why “architectural”?

A text filter has to be right about every sentence it sees. An architecture has to be right about one question: is this action inside what the task needed? The second question does not get harder as attackers get more inventive with wording, which is why the evaluation reports the architecture and the text filter separately.

Where the project stands

The planned rebuild is complete: every charter ran, every defect in the tracked register was fixed or explicitly ratified as intended behavior, and the evaluation reports real numbers from a real corpus with nothing fabricated. That does not mean feature-complete or ready to trust in production. Ferrite is a research prototype. The things to keep in mind are on one page, Limits, and the headline ones are:

  • The evaluation agent is scripted, so the results describe the architecture, not any particular model's behavior.
  • The corpus is self-authored and generated from templates, so the confidence intervals are optimistic.
  • Attacks that stay inside the prediction, using the same capability at the task's own site, are a structural residual.
