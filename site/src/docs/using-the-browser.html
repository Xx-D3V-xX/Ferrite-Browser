Ferrite is a normal browser with an agent panel beside it. This page covers the window, the shortcuts, the panels you can resize, what happens when a page asks for a dropdown, a dialog or a file, and what the crash banner means.

Which build has this

Everything here is in the source. The build on the releases page was published on 2026-10-02 from commit f4ed744, before the page-control overlays, resizable panels, DevTools and crash banner were written. The release page names its commit; build from source (Run it from source) to get them now. The screenshots on this page were rendered on Linux.

The window

Tab strip

  • Tabs share the strip equally, down to a minimum width, and the strip scrolls beyond that. A long title is cut with an ellipsis. The active tab keeps a minimum width so its close button stays reachable.
  • The close button shows on the active or hovered tab, and a middle-click closes a tab. Cmd/Ctrl+T or the + opens one.
  • A small dot on a tab means the page needs you: the accent colour while it waits on a dropdown or dialog, red after it stopped responding. This matters because a background tab's alert is otherwise invisible, and its page is blocked until you look.
  • The empty part of the strip drags the window, and a double-click maximizes it. On macOS the title bar is transparent and the strip holds the window buttons; on Linux and Windows the window keeps its normal frame.

Toolbar and address bar

Left to right: back, forward, reload (it becomes stop while a page loads), the address bar, the Agent button (a dot appears when something needs your decision), the audit shield and the menu. A thin band sweeping the toolbar's bottom edge shows loading.

  • An address with a scheme (https://…) or an about: page is opened as typed.
  • A bare host or path containing a dot and no spaces gets https://; localhost and IP addresses get http://.
  • Anything else is a Google search. The agent's own search is separate: its prompt still sends it to DuckDuckGo Lite and tells it not to use google.com, because Google's pages stayed blank in this engine when that was written. Whether Google's results page now renders well is unconfirmed (see Limits).
  • Clicking the bar selects everything. A zoom chip appears in it when the page is not at 100%, and a bookmark button saves the page.

The menu

Bookmarks, History and Downloads share one drawer. Browsing history is for the current session only and is not saved; bookmarks are. Downloads has a manual Download current page action, and clicks on <a download> links are not intercepted.

Keyboard shortcuts

Mod is Cmd on macOS and Ctrl everywhere else. These come from the shortcut table in the interface code, and they keep working while the address bar or the agent box has focus (editing keys such as Mod+A, C, V, X and Z still reach the field).

Typing, pointer and wheel input go to the page unless a field of the browser has focus or a page control is open. Not handled: input-method (IME) composition and HTTP basic-auth prompts. Non-US keyboard layouts, dead keys and key repeat have not been observed.

Panels you can resize

The agent, library (bookmarks, history, downloads) and settings drawers share the right-hand side, one at a time. DevTools and the audit panel share the bottom. Drag the edge between a panel and the page to resize it, and double-click the edge to reset it.

  • Side drawers are 300 to 760 px wide (380 by default); bottom panels are 140 to 720 px tall (260 by default).
  • The page always keeps at least 360 by 160 px, and sizes are re-fitted to the real window every time, so a size saved on a big monitor never swallows the page on a small one.
  • Sizes are saved when you release the mouse, in ui-layout.json in the data folder. If a size cannot be saved, the panel still resizes.

What a page can ask the browser for

Dropdown lists, alert(), confirm() and prompt(), the colour picker, the file picker and the page's context menu reach the browser as requests, and Ferrite draws each one itself as an overlay on the page. The page is blocked until you answer, and while one is open the page receives no pointer or key input. Every control can be answered or dismissed (Esc cancels it).

The page's text is untrusted. A dialog's message, an option's label or a menu row is drawn as plain text with control and bidirectional characters removed and lengths capped, and a dialog names the site it comes from and says it comes from the page, so a page cannot pass its words off as Ferrite's.

Known gaps

The file picker is a typed-path card, and the path the engine receives after you press Open has not been exercised against a real upload. HTTP basic-auth prompts are not handled at all, so a page behind basic auth gets no prompt. Select, confirm(), prompt() and the colour input were verified in the engine; the overlays were driven on Linux at normal pixel density, not on a Retina screen or a Mac.

The page's cursor (pointer, text, crosshair and so on) is followed; cursor: none shows the ordinary arrow.

When a page stops responding

If a page's script thread dies, the engine reports it and Ferrite leaves the page frozen on screen with a banner over it, plus the red dot on its tab. The banner is not a dialog: you can keep using the rest of the browser.

Reload
Gives the tab a fresh engine session and loads the same address again. Reload and address entry on a crashed tab also start a fresh session instead of talking to the dead one.
Details
Shows the reason and a backtrace, with a Copy button that copies a short report including the page address.
Dismiss
Hides the banner. The crash stays in DevTools' Engine tab and in the log file.

The agent panel

The panel is a chat. Each run is a turn with the steps the agent took, collapsed once it finishes, and its answer. Chats are saved and listed under the clock icon. The answer is rendered as Markdown: no HTML is interpreted, no images are fetched, and a link shows the site it really goes to and opens only when you click it. Settings and the cards that ask for your decision are covered in Getting started and Models and settings.
