**The one that matters for A7:** `js.execute` is no longer a runtime string
check. `ScopablePrimitive` is a separate 16-variant enum with no `JsExecute`
variant; every expected-side type is built from it, so an expected set
naming it is *unrepresentable*. `Primitive` (observed) keeps the variant
because the recorder must report it, and `Primitive::as_scopable()` is the
only bridge back, returning `None` for exactly that one. `ActionClass::Execute`
carries the general rule ADR-003 states, so it isn't a name special-case.
Proven by `compile_fail` doctest on `ScopablePrimitive` + tests
`js_execute_is_the_only_unscopable_primitive`,
`an_expected_capability_set_can_never_lower_to_js_execute`,
`a_primitive_is_convertible_exactly_when_its_action_class_is_scopable`.

**Verified by experiment, not claimed:** adding an unassigned
`ScopablePrimitive` variant really does fail to compile (`error[E0004]` at
`ScopablePrimitive::capability()`) — directive §8's gate. Tests written
alongside their data (ID validators, lowering table, golden fixtures) were
mutation-checked: five mutations each turned the right tests red.
`FixedClock` really is absent from a default build — `cargo doc` failed on an
intra-doc link to it until it was unlinked.

**Green at HEAD:** `just check`, `just test`, `cargo deny check` (exit 0),
`cargo doc -D warnings` with *and* without `test-util`, both doc CI scripts.

**Not done, deliberately:**
- **Config loading** (charter line). Nothing here needs a config *value* —
  taxonomy is closed and compile-time, scopes are authored per case, `Clock`
  takes none — and a mechanism with no caller is the dead machinery R9 exists
  to prevent. Filed **T-213** for A3.
- `docs/ARCHITECTURE.md` still doesn't exist (`CLAUDE.md` points at it, A0
  and A1 both left it); not in A2's write scope — someone should own it.

**Discovered, filed rather than dropped:**
- **T-211** — opaque origins (`about:blank`, `data:`, `blob:`) have no
  representation; `Origin` is http/https only. A6's recorder hits this first,
  and A2 deliberately did not guess the model.
- **T-212** — `DomainSuffix` doesn't reject public suffixes: `domain_suffix:
  ["com"]` normalizes cleanly and admits the whole TLD. The one remaining way
  the scope algebra can fail *open*, and ADR-004's weak-scope reporting does
  not catch it (it reports as `domain_suffix`, not `task_open`).
- Reconciliation, not a defect: §8 lists **17** primitives, the A2 brief said
  16 (the *scopable* count). Both explicit and test-pinned.
