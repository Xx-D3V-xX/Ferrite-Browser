\section{Implementation}
\label{sec:implementation}

\ferrite{} is implemented in Rust (edition 2021) as a Cargo
workspace of \todo{N} crates totalling approximately \todo{X}
lines of code.
The browser is built on Servo v0.0.5~\cite{servo} for rendering
and Iced~\cite{iced} for the UI shell.
