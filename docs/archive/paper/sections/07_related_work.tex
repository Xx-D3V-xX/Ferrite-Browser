\section{Related Work}
\label{sec:related_work}

\subsection{Browser Security and Compartmentalization}

Capsicum~\cite{watson2010capsicum} introduced capability-mode
processes to FreeBSD, restricting applications to explicitly
granted file descriptors and system calls.
COWL~\cite{stefan2014cowl} extended label-based mandatory
access control to browser workers, preventing cross-origin
information leaks in web applications.
RLBox~\cite{narayan2020rlbox} sandboxed third-party libraries
in Firefox using WebAssembly, demonstrating practical capability
isolation in a production browser.
\ferrite{} extends this lineage to the agentic context, where
the principal is an AI agent rather than a browser worker or
library.

\subsection{Prompt Injection and Agentic Security}

Greshake et al.~\cite{greshake2023not} provided the first
systematic study of indirect prompt injection, demonstrating
that web content could hijack LLM agents browsing on behalf
of users.
Nasr et al.~\cite{nasr2025} evaluated twelve prompt injection
defenses across models from OpenAI, Anthropic, and DeepMind,

\subsection{Transparency and Auditability}

Certificate Transparency~\cite{laurie2013rfc6962} established
append-only Merkle logs for public auditability of TLS certificate
issuance, enabling detection of mis-issuance.
Sigstore/Rekor~\cite{sigstore_rekor} extended this model to
software artifact signing and supply chain verification.
\ferrite{} applies the same cryptographic auditability primitive
to browser agent actions, enabling post-hoc verification that
every action was authorized under the active policy.
